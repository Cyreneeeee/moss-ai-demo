# MOSS AI · Interactive Portfolio Demo

A standalone interaction demo by 蔡妙泉, reconstructed from the MOSS project capabilities for portfolio presentation.

## Scope

- Uses a fictional AI note-taking product brief and preset generation rules.
- Does not connect to the original project backend or invoke live LLM/RAG services.
- Demonstrates workflow stages, three knowledge reuse strategies, editable slides, and HTML export.
- Contains no original customer documents, history, credentials, or private knowledge base.
- The original system's PowerPoint export is not provided by this static demo.

Open `index.html` locally, or use the GitHub Pages URL shown in repository settings.
